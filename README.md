# 🤖 AI Прескоринг Кандидатов (HeadHunter)

Веб-приложение на Streamlit для автоматического прескоринга кандидатов с HeadHunter с помощью GPT-4o-mini.

Парсит вакансию и резюме → извлекает структурированные данные → отправляет в OpenAI для анализа соответствия → выдаёт оценку от 1 до 10.

---

## ⚡️ Возможности

- **Парсинг HH.ru:** Извлечение данных из вакансий и резюме через BeautifulSoup + requests.
- **AI-анализ соответствия:** GPT-4o-mini оценивает, насколько кандидат подходит на вакансию.
- **Оценка качества резюме:** Отдельная оценка понятности и структуры резюме.
- **Веб-интерфейс:** Удобный UI на Streamlit — вставь ссылки, получи результат.
- **Конфиденциальность:** Данные обрабатываются через API, ничего не сохраняется локально.

## 🛠️ Установка и запуск

1. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Укажите OpenAI API Key** в `streamlit_app.py` или через переменные окружения:
   ```bash
   export OPENAI_API_KEY="sk-..."
   ```

3. **Запустите приложение:**
   ```bash
   streamlit run streamlit_app.py
   ```

4. **Откройте в браузере:** `http://localhost:8501`

---

## 💻 Как использовать

1. Вставьте ссылку на вакансию HH.ru в первое поле.
2. Вставьте ссылку на резюме HH.ru во второе поле.
3. Нажмите **"Проанализировать соответствие"**.
4. Получите:
   - Короткий анализ кандидата
   - Оценку качества резюме
   - Финальную оценку от 1 до 10

## 🧠 Технологии

- **Python** — основной язык
- **BeautifulSoup 4** — парсинг HTML
- **requests** — HTTP-запросы к HH.ru
- **Streamlit** — веб-интерфейс
- **OpenAI GPT-4o-mini** — AI-анализ и оценка

---

> ⚠️ **Важно:** Проект использует публичные страницы HH.ru. При массовом парсинге рекомендуется добавить задержки (`time.sleep`) и прокси.
